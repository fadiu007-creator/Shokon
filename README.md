# SHOKON

SHOKON is a marketplace MVP for booking platonic companionship and social experiences by the hour.

## MVP
- Discover people by role and location
- Search and category filters
- Provider profiles and ratings
- Hourly pricing
- Demo booking modal
- Responsive mobile-first UI
- Safety/boundary positioning

## Next
Connect Supabase Auth + Postgres for accounts, provider profiles, availability, bookings, messaging and reviews; then add real payments.
